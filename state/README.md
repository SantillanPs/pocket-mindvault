# Current State

This directory is for small, temporary continuity state: active work, unfinished tasks, current objectives, waiting states, and decisions that are still in progress.

State is not a journal and not a memory database.

## Rules

- Keep state small.
- Create/update it only when work actually needs to continue across sessions.
- Remove or archive completed state.
- Do not write heartbeat entries.
- Do not duplicate durable knowledge here.
- If there is no unfinished work, no state file is required.

The live record is `state/current.md` when unfinished work exists. `HANDOFF.md` is kept only as a compatibility pointer for tooling that still references it; it is not authoritative.
