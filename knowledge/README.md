# Durable Knowledge

This directory is the home for information worth preserving as an artifact rather than as personal memory.

Examples:

- durable architectural decisions
- validated solutions
- expensive-to-reconstruct research
- project knowledge
- validated lessons

Do not create a file here merely because a conversation happened.

Prefer updating an existing artifact over creating another file. New files should represent genuinely distinct durable knowledge.

Small personal facts belong in Mnemosyne instead. Temporary work belongs in `state/`. Raw history belongs in the archive.
