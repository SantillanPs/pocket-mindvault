# Pattern Reports

Pattern reports are generated when the available data can answer a useful longitudinal question or when the User asks for analysis.

There is no fixed week/month schedule. Do not manufacture a report to satisfy a calendar deadline.

## Evidence threshold

The AI should consider:

- how many observations exist;
- how consistent the measurements are;
- whether the same metric was measured across comparable periods;
- whether the apparent pattern could simply be noise or a change in measurement;
- whether the conclusion is descriptive or causal.

Small samples can support observations such as "sleep was lower on these recorded days." They generally cannot support strong causal claims.

## Report structure

1. **What the data shows** — direct observations with the relevant time window.
2. **Patterns** — repeated changes or relationships supported by the history.
3. **Uncertainty** — important limitations or alternative explanations.
4. **Experiments** — up to 1–3 small things worth testing when appropriate.
5. **Follow-through** — only for experiments that were deliberately tracked.

Reports should be concise and useful. Do not create a report merely because enough time has passed.
