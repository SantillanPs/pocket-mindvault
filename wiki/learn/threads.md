## Lifecycle

A thread may be:

- **active** — attached to a real need and worth continuing;
- **closed** — the need was met or dropped;
- **shelved** — the User explicitly wants to keep an interest without an active need.

Do not create a thread for every curiosity. Do not maintain a daily log to prove activity. Update this file only when meaningful thread state changes or durable evidence appears.
